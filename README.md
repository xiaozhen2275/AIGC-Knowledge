# AIGC-Knowledge

这是一个面向 AIGC 内容生产、线下活动交付和个人知识资产沉淀的知识库工程。

当前版本聚焦于《1000个铁粉，打造个人品牌的底层逻辑》三期线下 AI 读书演讲工作坊：用 2 小时帮助普通职场人从一本书里的一个观点出发，完成一段能讲出来的 3 分钟表达，并沉淀成一张可复用的知识资产卡。

## Agent 启动入口

Claude Code、Codex、WorkBuddy 或其他 AI agent 进入本项目后，统一按下面顺序读取：

1. `AGENTS.md`
2. `00_AGENT初始化总纲.md`
3. `00_使用说明.md`
4. 本次任务相关文档

`AGENTS.md` 是最高优先级中控入口；`CLAUDE.md` 和 `WorkBuddy_启动提示词.md` 是不同工具的桥接入口，不单独维护规则。

## 核心文档

- `00_使用说明.md`：资料包使用入口和内容清单。
- `01_总方案.md`：三期活动整体定位、流程、人数分流和成功标准。
- `02_第1期_读懂一本书_主持稿.md`：第 1 期主持稿。
- `03_第2期_连接自己的经验_主持稿.md`：第 2 期主持稿。
- `04_第3期_分享出去_主持稿.md`：第 3 期主持稿。
- `05_WorkBuddy提示词库.md`：现场可复制使用的提示词。
- `06_现场成果模板.md`：3 分钟演讲卡、知识资产卡和讨论模板。
- `07_招募文案与海报文案.md`：朋友圈、小红书、私聊和海报文案。
- `08_报名表与反馈表.md`：报名、反馈和复盘表。
- `09_运营检查清单.md`：活动前、中、后的执行清单。
- `10_海报设计简报.md`：海报视觉方向和物料延展说明。
- `11_课程内容设计稿.md`：课程内容展开和现场教学逻辑。

## 目录规范

- 根目录：正式主文档，当前 `00` 到 `11` 文件不要随意移动。
- `outputs/`：新增或改版后的正式交付文档。
- `drafts/`：AI 临时草稿、待确认版本、不同方案对比。
- `archive/`：被替换的旧版本、历史备份。
- `assets/`：图片、海报、封面、二维码、可视化素材。
- `logs/`：修改记录、复盘记录、agent 操作摘要。

## 内容原则

- 不把活动改成纯 AI 工具课。
- 不把活动改成卖课页或高压转化现场。
- 不改成持续打卡、重运营社群或长期陪跑产品。
- 不默认要求学员读完整本书。
- 不强制学员公开发布内容。
- 所有新增内容都要服务“2 小时现场带走可见成果”。

## Git 提交规范

提交信息必须使用中文，格式为：

```text
动词 + 对象 + 目的
```

示例：

```text
新增Agent统一启动入口
更新资料包使用说明
修正资料包清单遗漏
整理知识库产物目录
初始化AI读书会知识库工程
```

每次提交只覆盖一类明确变更；不要使用 `update`、`fix`、`修改一下` 这类泛泛表述。
